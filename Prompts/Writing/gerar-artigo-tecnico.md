# Gerar Artigo Técnico

## Descrição
Prompt para gerar artigos técnicos, tutoriais ou documentação.

## Prompt
```
Escreva um artigo técnico sobre [tópico] com os seguintes requisitos:

- Comprimento: [quantidade de palavras]
- Público-alvo: [descreva o público]
- Tom: [formal/casual/técnico]
- Incluir: [exemplos/diagramas/código/etc]
- Estrutura:
  1. Introdução
  2. Conceitos principais
  3. Exemplos práticos
  4. Conclusão

Certifique-se de que o conteúdo é preciso e atualizado.
```

## Uso
Customize o tópico e requisitos conforme necessário.
