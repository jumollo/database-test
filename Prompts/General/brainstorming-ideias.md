# Brainstorming de Ideias

## Descrição
Prompt para gerar ideias criativas sobre um tópico específico.

## Prompt
```
Faça um brainstorming de ideias para [tópico/projeto].

Requisitos:
- Gere pelo menos 10 ideias diferentes
- Varie entre práticas e criativas
- Indique o nível de viabilidade de cada ideia
- Forneça um breve resumo de cada uma
- Sugira a melhor opção para começar

Contexto adicional: [descreva o contexto/restrições]
```

## Uso
Customize o tópico e contexto para sua necessidade específica.
