# Resumir Texto

## Descrição
Prompt para resumir textos longos em versões mais concisas.

## Prompt
```
Por favor, resuma o seguinte texto de forma clara e concisa:

[Cole seu texto aqui]

Requisitos do resumo:
- Máximo de [quantidade] palavras
- Mantenha os pontos principais
- Use linguagem clara e simples
- Formato: [parágrafo/bullets/estruturado]

Após o resumo, liste os 5 pontos principais mais importantes.
```

## Uso
Cole qualquer texto (artigo, documentação, e-mail longo, etc) e obtenha um resumo conciso.
