# Gerar Função JavaScript

## Descrição
Prompt para gerar uma função JavaScript completa com documentação e exemplos de uso.

## Prompt
```
Crie uma função JavaScript que [descrição da funcionalidade].

Requisitos:
- Use ES6+ syntax
- Inclua JSDoc comentários
- Adicione tratamento de erro
- Forneça exemplo de uso
- Retorne um objeto com status e dados

Exemplo de entrada: [seu exemplo aqui]
Exemplo de saída esperada: [sua expectativa aqui]
```

## Uso
Customize o prompt acima com sua funcionalidade específica e execute com sua IA preferida.
