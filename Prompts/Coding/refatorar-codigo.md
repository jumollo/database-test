## Descrição
Prompt para solicitar refatoração de código existente, melhorando legibilidade e performance.

## Prompt
```
Refatore o seguinte código:

[Cole seu código aqui]

Objetivos:
- Melhorar legibilidade
- Seguir as melhores práticas da linguagem
- Reduzir complexidade ciclomática
- Adicionar comentários explicativos
- Otimizar performance se possível

Explique as mudanças realizadas.
```

## Uso
Cole seu código no prompt e deixe a IA sugerir melhorias.
