# PromptdaJu 🤖

Repositório dedicado à organização e armazenamento de prompts de IA.

## Estrutura

```
PromptdaJu/
├── Programacao/          # Prompts para desenvolvimento e programação
├── Escrita/         # Prompts para escrita e conteúdo
├── Geral/         # Prompts gerais e diversos
└── README.md        # Este arquivo
```

## Como Usar

1. **Adicionar um novo prompt**: Crie um arquivo Markdown (`.md`) na pasta apropriada
2. **Nomear o arquivo**: Use nomes descritivos e em minúsculas com hífens (ex: `gerar-funcao-javascript.md`)
3. **Formato**: Cada arquivo deve conter:
   - Título do prompt
   - Descrição breve
   - O texto completo do prompt

## Exemplo de Estrutura de Prompt

```markdown
# Nome do Prompt

## Descrição
Breve descrição do que este prompt faz.

## Prompt
[Seu prompt aqui]
```

## Categorias Disponíveis

- **Programacao**: Prompts para codificação, debugging, refatoração
- **Escrita**: Prompts para escrita criativa, técnica, copywriting
- **Geral**: Prompts gerais, brainstorming, pesquisa
